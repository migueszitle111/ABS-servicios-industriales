# ABS

Sitio web de `ABS Servicios Industriales` construido con `Next.js 15`.

## Incluye

- Navegación por secciones con `@alvalens/react-fullpage-snap`
- Página principal de una sola ruta con:
  - `Inicio`
  - `Servicios`
  - `Como trabajamos`
  - `Portafolio`
  - `Contacto`
- Animaciones con `framer-motion`
- Imágenes del portafolio desde `public/image/portafolio`

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run start
```
